## 線上預覽（GitHub Pages）

啟用 GitHub Pages 後，網址為：

**https://cheng9487.github.io/gay/**

### 如何啟用 GitHub Pages（約 30 秒）

1. 進入本倉庫 → **Settings** → 左側 **Pages**
2. **Source** 選擇 `Deploy from a branch`
3. **Branch** 選 `main`，資料夾選 `/ (root)`
4. 點 **Save**
5. 等待 1–2 分鐘，重新整理即可看到網站

> 已包含 `.nojekyll`，可直接部署純 HTML，無需額外建置。
